## Reading versus reproduction

Eleven self-contained HTML reading artifacts now physically live here, byte-for-byte.
Original paths remain relative compatibility symlinks for hash ledgers, source links
and existing tools. The [relocation manifest](relocations.json) records both paths
and hashes. There is one physical copy, not two independently editable reports.

Protocols, aggregate tables, source packages and HTML with relative evidence links
remain at their original locations in this first slice. Each week links them explicitly.
Do not regenerate historical reports to complete filing: some builders access private
inputs and overwrite accepted evidence. Download raw HTML to read it; GitHub displays
HTML source and may display legacy symlinks as text.

Scientific implementation is being extracted into [src/neuro](../src/neuro/README.md).
Weekly folders do not own competing copies of shared algorithms. Frozen executed
source and current maintained code are distinct identities; no migration is a new
scientific result or a certification of historical replay.

See [migration status and checks](../docs/reorganization.md). No raw data, model,
prediction, runtime, submodule or retained worktree was moved.
