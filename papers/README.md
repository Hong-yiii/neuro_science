## How To Use This Folder

- Store paper notes, BibTeX entries, reading queues, and links here.
- Prefer notes over raw PDFs when possible.
- Do not commit copyrighted PDFs by default unless Hongyi explicitly asks and has the right to store them here.
- When a paper changes the project direction, summarize the durable takeaway in `context/` or `docs/`.
