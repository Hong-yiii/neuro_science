# Papers

This folder is for prospective path prediction, hippocampal navigation, neural coding, representation learning, and the later artificial-agent/RNN comparison.

## Start Here

Read `reading-roadmap.md`. It orders papers by project dependency and states the
specific knowledge and method to extract from each one.

## How To Use This Folder

- Store paper notes, BibTeX entries, reading queues, and links here.
- Prefer notes over raw PDFs when possible.
- Do not commit copyrighted PDFs by default unless Hongyi explicitly asks and has the right to store them here.
- When a paper changes the project direction, summarize the durable takeaway in `context/` or `docs/`.

## Suggested Note Shape

```text
title:
authors:
year:
link:
why it matters:
methods to borrow:
limits / caveats:
connection to H1/H2:
```
