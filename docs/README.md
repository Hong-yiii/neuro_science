## One owner per document role

The root README is the showcase/reader entry point; the package README owns checkout
usage, whole-workflow contracts and helper boundaries; software design owns as-built
engineering diagrams and coupling (not a pure-library target architecture). `report/`
owns current editorial work, `history/week-.../` owns chronological reading, and this
directory owns living methods and recovery. The [operations archive](../history/operations/README.md) stores dated
logs rather than competing “current” instructions.

Older direction notes, pilot plans and professor deliveries remain historical context.
The active report-first direction and implemented three-study package are recorded
in [AGENTS.md](../AGENTS.md). The [accepted endpoint notebook](../report/README.md)
replays saved inputs/models. The [October23 direction](notebook-package-plan-20261023.md)
now has implemented runnable construction/model notebooks using supplied source data;
current source-notebook outputs are cleared. The October26 ledger records non-fitting
compact-source validation; earlier invented and private real-run results retain their
dated evidence, not a claim of executing today's notebooks. Earlier “no notebook” statements
in architecture-era documents are historical, not the current artifact inventory.
Neither filing nor packaging authorizes fits, private replay, data downloads or
changes to scientific conclusions.
