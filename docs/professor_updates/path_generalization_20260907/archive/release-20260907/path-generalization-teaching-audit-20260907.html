1. Scientific objective and actual measurement/dataflow

Objective. The thesis question is whether cue-period hippocampal activity contains information about the later observed navigation path beyond start and goal. The current report is a development audit: it asks which existing analysis direction is defensible, not whether a final biological claim has been confirmed.

Actual measurement. The data used here are fixed-scope, selected-unit cue-period spike-count derivatives linked to behavior-derived route components. Track A/B use a constructed finite-source pseudopopulation benchmark for the original interior-route target. Track C uses operational per-unit real-trial prediction: for one source trial and one unit, the input cue count/exposure, endpoint, trial index, and cue duration are available before the future route-component label is known.

Dataflow. Source trial identity is preserved first. Behavior-only route labels are frozen next. Training-only preprocessing and models are fitted on development train rows, then evaluated on source-disjoint validation objects with proper scores and nulls. The flow is deliberately written this way because the conclusion depends less on model glamour than on whether each row means a real source trial, a time bin, a unit-row, or a synthetic recombination.

Claim ceiling. This report does not verify a simultaneous 195-cell population, does not evaluate the original exposed test split, and does not claim intention, planning, internal graph computation, or absence of hippocampal path information. It narrows the next defensible experiment.

3. Zoom out: thesis H1 is not the same as the diagnostics

The thesis-level question is H1: whether hippocampal population activity during the cue period contains prospective information about the subsequently observed navigation path beyond what is already explained by start and goal. It has two linked pieces. H1a is the information claim: cue-period neural features improve held-out path prediction beyond a start-and-goal baseline. H1b is the structure claim: whatever information exists has reproducible low-dimensional organization rather than being a fragile decoder artifact.

This report keeps H1 separate from the four development diagnostics. The frozen protocol called them H1–H4, but that naming is now confusing because the repository already uses H1 for the thesis question. Here they are D1–D4: finite synthetic sampling; representation/optimization sensitivity; source/session relationship changes; and source-preserving route-component feasibility. A diagnostic can be true even when H1 is not yet supported. For example, D1 can show that finite pseudorow sampling was unstable without showing that real cue activity predicts a future route.

The outcome measured here is the observed path, not a directly observed plan. The maze graph is a measurement device: positions are mapped to graph nodes and route components. It is not itself the hypothesis. A route component such as D_N_R_T__N_R_M is an operational behavioral label extracted from paths; it is not a neuron, not a latent dimension, and not a proof of an internal cognitive graph.

The most conservative useful conclusion is therefore: after correcting the target semantics and auditing the old pseudopopulation machinery, the strongest next direction is to test frozen route-component targets with source-preserving trial-linked features, endpoint/time controls, coherent nulls, and genuinely reserved evaluation observations. That direction is credible because it reduces pseudopopulation assumptions; it is not yet confirmed because the current development split and original holdout exposure cap the claim.

4. Prior observations that motivated this audit

Before reading the new outcome tables, the project already had several reasons to be cautious. The earlier V6–V9 work used a fixed selected 195-unit scope and a behavior-derived route-component target. It was not an unbiased all-cell population survey, and it was not a verified simultaneous 195-cell recording. That does not make the analysis useless, but it changes the claim: the old common-panel pseudopopulation is a conditional benchmark over selected source pools, not a direct measurement of one animal's full population state on one trial.

The second prior observation was behavioral. The target word absent was misleading. It meant the selected directed component was not in the interior-corridor set: for a route-component sequence of length L, remove component 1 and component L and test positions 2..L−1. A two-component route therefore has an empty interior even if the selected edge appears as the terminal component. A route can share a prefix, an interior corridor, or a terminal segment for different reasons. A shared prefix can be explained by start location, and a shared suffix can be explained by goal. Interior segments are more interesting for H1b, but only if the analysis separates them from endpoint identity and cue/task condition.

The third prior observation was statistical. Synthetic pseudorows can be generated in large numbers, but the number of independent source trials does not increase. In ML terms, this is like heavy augmentation from a small training set: it can stabilize an optimizer and estimate a chosen conditional benchmark more accurately, but it cannot by itself create a new validation distribution. Exact enumeration and moment calculations were therefore predeclared as diagnostics before treating any model score as neuroscience.

The fourth prior observation was about representation learning. PCA and CEBRA are useful instruments, but neither is the thesis. PCA components are coordinates fitted from data. CEBRA embeddings are learned nonlinear representations. A high score after trying many dimensions, seeds, and budgets would need a family null because it may reflect search over analysis choices. A low score would not prove the hippocampus lacks path information because the target, cells, cue window, nuisance controls, and validation support can all be limiting.

The final prior observation was about data governance. The original holdout has already been exposed in earlier project history, so this development work cannot become pristine confirmation. The study's guarded Track C extraction streamed the mixed-split importer and consulted split metadata; only permitted development records reached analysis. The later report-generation step reads those derived artifacts rather than reopening the importer. The experimental program is complete, but it remains a development study rather than confirmation.

That framing also protects the positive future case. If a later reserved-data analysis succeeds, it will be stronger because this report has already separated the measurement object, the nuisance controls, the null family, and the claim ceiling. If it fails, the result will still be interpretable as a design or support limit rather than as a vague statement that hippocampal prospective coding is absent. Either way, the next reader can see exactly which bridge from behavior to neural inference is carrying the load.

5. Measurement ladder: what each object is, and what it is not

A source trial is the behavioral trial identity that must keep all derivatives together. A trial in ordinary language is the animal's attempt in the maze. In these tables, the term source is used because one biological trial can create several derived rows: time bins, unit-specific rows, or pseudopopulation assemblies. Treating those derivatives as independent examples would be pseudoreplication.

A bin is a time slice of the cue period. In the old whole-cue Track A/B setup there are ten 100 ms cue bins. Adjacent bins are not independent biological trials. A unit is a putative neuron/cell from spike sorting; its cue count is a feature. A session is a recording day/session. Units from different sessions are not automatically simultaneous with each other, so combining them into a single vector is a constructed benchmark unless simultaneity is verified.

A graph node is a maze-location label from the path measurement pipeline. The spatial bin IDs are categorical/topological, not row-major coordinates. A directed component is an ordered edge-like route token such as center-top to right-top. A latent dimension is an embedding coordinate produced by PCA or CEBRA. It is not a cell, and its dimensionality is a modeling choice.

The end-to-end flow is: source trial identity → cue-period spike counts by unit/bin → behavior-only route labels from subsequent path → training-only preprocessing and model fitting → held-out validation scores → null or sensitivity checks. The route label must be constructible from behavior alone; neural activity is not allowed to help define the target. Inputs for a new prediction must be known before the future route label is known.

Inclusion and time windows. The 19,162 behavioral sources are successful trials following successful trials, inherited from the V6 development cohort; timeout/unsuccessful cases are not this evaluation population. A/B use the nominal first second of cue activity in ten 100 ms bins. C uses the full recorded cue-window count divided by its measured exposure, with cue duration also in the baseline. These window and cohort differences are another reason not to rank A/B and C scores as the same task.

How a pseudorow is constructed. A/B begin with masked source storage, not a complete 104×29-cell recording: off-session cell entries are unavailable, not zero spikes. To construct a present row, the assembler first chooses that label, then chooses one present source trial from each of seven sessions and joins its observed cell block. The same source supplies all cells and ten bins within that session block. Thus one row combines seven real trials, and its construction requires the future class label. Recorded zero-count bins remain zeros; unavailable cells are never imputed as zeros. C instead constructs each unit's feature row from one real trial without needing its future path label. Its evaluation is still conditional on the stated successful-trial cohort.

Track C's export is the cleanest current example of this ladder. The guarded access streamed a mixed-split file and yielded only train/validation rows. It explicitly saw and skipped 12,486 test rows, yielded zero forbidden rows, and exported 64,051 selected-cell unit-trial rows over 19,162 development source IDs. This is a receipt that the derived export was guarded; it is not a re-audit of the original raw importer, which is outside this report's allowed scope.

There is no claim here that the actual train/validation split leaked source IDs. Track A/B validation source pools are source-disjoint, and Track C keeps all derivatives of a source trial together. A source-ID-control leak was a preflight implementation bug fixed before these fits; the assembly-transfer diagnostic intentionally uses seen training sources and is labeled as a same-source diagnostic, not validation. The recommender-system analogy is only a warning about what source leakage would look like if it happened.

6. How to read the scores: BA, probability scores, seeds, and intervals

Balanced accuracy is the average of sensitivity and specificity. It gives each class equal importance even when class counts differ. In Track A exact Q, the validation object has 24 absent and 6 present source-combination rows, but each class receives total weight 0.5. That is why ordinary row accuracy is not the target metric. BA is useful for directional classification, but it ignores confidence: a model that predicts 0.51 and a model that predicts 0.99 receive the same class decision if both cross the threshold.

Log loss and Brier score are proper probability scores. They measure the quality of predicted probabilities, combining discrimination and calibration rather than serving as standalone calibration tests. Log loss is especially strict about confident wrong predictions. In Track C, the primary metric is Δ log loss = baseline log loss − augmented log loss. Positive means adding cue-rate information improved held-out probability predictions beyond endpoint, trial index, and cue-duration controls. Negative means the cue-rate term made predictions worse.

AUROC is a ranking metric. It asks whether positives tend to receive higher scores than negatives. For ridge outputs in Track A, probability scores use a clipped transformation for log loss/Brier, but AUROC uses the unbounded decision score to avoid clipping-induced rank ties. That distinction matters because a probability score and a rank score answer different questions.

Seeds are not independent scientific replications. Assembly seeds change synthetic pseudorows; optimizer seeds change model initialization or stochastic training. Means over seeds can summarize algorithmic variability, but they are not confidence intervals over animals or sessions. When figures show min–max bands here, the band says what varied: random source subset, pseudorow assembly, or optimizer seed. It should not be read as a biological CI unless the resampling unit and exchangeability assumption justify that interpretation.

For the same reason, a family maximum is a different estimand from an average seed. The 50-grid Track B primary panel diagnoses variability across assembly and optimizer seeds. The narrower 14-configuration null family asks a different question: if the source labels carried no usable relationship under the conditional permutation, how large a best observed BA could we get after trying the predeclared dimension, row, and budget variants? Mixing those two objects would make the uncertainty look better than it is.

8. Track A: exact conditional benchmark and finite-source diagnosis

Track A kept the old interior-component target so the old V8b/V9 claims could be audited on the same target. The target-semantics correction is load-bearing: the old word absent meant the selected directed component was not in positions 2..L−1 after dropping the first and last route components. It did not mean the edge was nowhere in the route. Fifty-one old fixed-4→3 absent sources actually used the edge outside the interior set; all 51 were two-token routes, where the interior set is empty, and had empty V6 QC flags. The right correction is semantic, not a new truncation or clock-bug story.

The exact empirical-Q object is deliberately small and finite. It enumerates validation session-block source combinations: 24 absent and 6 present. It assigns total weight 0.5 to each class and uniform weight inside each class. These product rows can be dependent and can even yield identical neural vectors. They are a conditional benchmark over the finite source pools, not 30 independent biological trials.

Q(Y=0)=Q(Y=1)=1/2. For class y and session block j, draw S_j uniformly from the saved finite source pool for that class/session. The pseudorow is X=(X_1(S_1),...,X_J(S_J)). Under this constructed product Q, μ_y concatenates the block means and Σ_y is block diagonal across sessions. The balanced class-mixture covariance is 0.5 Σ_0 + 0.5 Σ_1 + 0.25(μ_1−μ_0)(μ_1−μ_0)^T.

The last rank-one term can induce between-session covariance in the constructed mixture even when no simultaneous between-session interaction was measured. That is a mathematical identity under the product-Q construction. It is not biological proof of coordinated hippocampal dynamics. For pooled class+time PCA, the covariance is different again: the mean and covariance are averaged over both class and cue time, so shared time as well as class can contribute. The whole-cue rank-one statement cannot simply be transferred to pooled-bin PCA.

Track A also derives the finite-source mean uncertainty under the zero-true-contrast toy assumption. If a session/block coordinate has variance σ² and class means are estimated from n0 and n1 finite sources, the null class-mean difference has uncertainty σ²(1/n0+1/n1). The expected spurious balanced-mixture between-class covariance contribution is one quarter of that trace summed over coordinates; any real nonzero class contrast would add its own between-class term. This is exactly why tiny source pools can create apparent cross-session structure without a real simultaneous population effect.

The Gaussian known-truth controls are the clean counterexample. They simulate a world where the true null BA and AUROC are exactly 0.5 for any frozen classifier under the stated Gaussian/no-signal assumptions. With train N=3 and validation N=1 per class/session, 30 of 100 simulation seeds have perfect empirical-Q BA and 16 have inverted BA. These are toy simulation seeds and Gaussian coordinates, not biological replications and not universal sample-size advice. Their role is narrower: prove that a finite empirical benchmark can be perfect or inverted even when the population truth is chance.

The practical Track A conclusion is restrained. Finite synthetic sampling variance shrinks as rows/class increase. Moment-exact references are useful. Source-budget and leave-one-session checks show source composition can dominate the score. None of that rescues the old biological claim; it tells us how not to overread it.

9. Track B: native CEBRA observed fits and exact audited family null

Track B tests whether representation, dimension, optimizer seed, row budget, or training length explain the old CEBRA weakness. The input to CEBRA is raw standardized cue-count data, not upstream PCA. The inspected pointwise model maps 29 input coordinates through hidden layers 32 → 32 → 16 → d, L2-normalizes the d-dimensional embedding, and then a 10-bin downstream logistic head evaluates the exact-Q target. Output dimension 29 is therefore not an invertible no-compression control: the mapping is nonlinear and normalized.

The observed crossed grid has assembly seeds 0–4 crossed with optimizer seeds 0–4 for both Time and Behavior objectives at dim 8, 64 rows/class, and 1000 updates. This report reads completed fit_info.json receipts for fit inventory and uses the audited summary/exact audit for inference. The 50 primary observed fits all have training BA=1, but their source-disjoint exact-Q validation means are Time 0.249 and Behavior 0.352. The variance decomposition shares provided for the fixed 5×5 grids are descriptive: Time assembly 16.5%, optimizer 7.2%, interaction 76.3%; Behavior assembly 24.4%, optimizer 20.4%, interaction 55.2%. They are not biological variance components and not causal attribution.

The A0/O0 sensitivities do not give a stable rescue. Dimensionality, row count, and longer budget can move individual scores, and the exact observed 14-config family maximum is 7/12 (0.583). The completed exact family null has 18/20 null maxima at least that large, corrected p=19/21=0.905. Larger dimensions and more rows are not consistently better, and the 14-config A0/O0 family does not license choosing the best seed from the wider 5×5 grid.

The assembly-transfer diagnostic is especially useful. CPU forward-only replay did not fit new models. It loaded the 50 observed primary checkpoints and evaluated new mixtures from the same training source pools. Own training assemblies have BA=1. New mixtures from the same training sources remain near perfect: Time mean 0.9925 and Behavior mean 0.997656. Source-disjoint validation drops to Time 0.249167 and Behavior 0.351667. That pattern localizes the gap across source pools, not merely across the 64 particular sampled rows.

Same-training-source transfer is still not independent validation. It says the model learned structure that generalizes across recombinations of sources it has already seen. For H1a, the needed object is prediction on source-disjoint real observations with labels and preprocessing frozen before evaluation. The final Track B verdict is therefore non-positive under the audited development artifact contract. The exact correction changes p from the stale producer float value to 19/21; it does not change any model, prediction, or checkpoint.

10. Track C: source-preserving per-unit route-component analysis

Track C is not a direct score comparison with Track A/B. It changes the evaluation object to reduce a major assumption. Instead of building a global common-panel pseudopopulation, it keeps real source trials and per-unit observations. That means it cannot claim a simultaneous population decoder, but it also does not invent one. This is closer to an operational route-component analysis that could eventually support H1a if it is repeated with reserved observations and verified metadata.

The target definitions are frozen and separate. middle is the saved artifact name for the original interior-corridor target: whether D_N_R_T__N_R_M appears after dropping the first and last route components. anywhere asks whether that same original component appears anywhere in the route signature. supported_middle is the saved name for the supported-interior candidate D_N_C_M__N_C_B, selected by a train-behavior-only support ranking over 24 static directed components. The ranking did not use neural response values.

The real-route examples matter pedagogically. The dominant middle-present route is CT→RT→RM→RB, 459 of 475 positive examples. Two dominant old-absent routes are RT→CT→CM→RM→RB (99 examples) and CT→RT→RM (50 examples). A full route signature can be a noncontiguous inferred corridor-token sequence; 23 of 660 signatures had noncontiguous tokens. Therefore binary adjacent-node edge evidence is stronger than assuming the full signature is an exact graph walk.

The model is intentionally boring. The baseline has full endpoint-pair intercepts plus standardized trial index and cue duration. The augmented model adds standardized log1p(cue count/exposure). Continuous inputs are centered by training endpoint-specific means before residual standardization; validation means are never learned. Endpoint intercepts are unpenalized so the baseline is not deliberately underfit. The primary statistic is held-out Δ log loss, aggregated per unit within session and then equally across sessions.

11. Defensible research direction after this report

The next direction should not be try a bigger model until the exact-Q BA looks good. The lazy scientific move is to remove an assumption, not add capacity. Pseudopopulations are not universally invalid: condition decoding and source-safe cross-validation can be legitimate, and the Meyers Neural Decoding Toolbox tradition is a useful reference for careful pseudopopulation decoding. But this project's thesis asks about trial-linked cue-period path information. For that, the source trial and recording group matter.

The concrete next project is a source-preserving route-component validation set. Dataset schema: one row per source trial × unit with source_id, recording_group/session, split, unit ID, cue-window spike count and exposure, start, goal, endpoint pair, trial index, cue duration, route signature, and frozen binary route-component targets. Keep all rows derived from one source trial in the same split; if simultaneous recording groups are verified, add a separate within-group population table rather than mixing it with per-unit rows.

Freeze a small behavior-only target set before fitting. The first candidate is the supported-interior component D_N_C_M__N_C_B (parent shorthand: D_C_M_C_B) because Track C found support across 11 modeled sessions without using neural response values for selection. Plan training support and enough prospectively reserved validation trials to represent both route variants. Fix inclusion and allocation rules before neural evaluation; do not discard a one-class validation group after inspecting responses. Proper scores remain reportable there, although within-group BA/AUROC may be undefined.

Baseline: endpoint-pair intercepts plus trial index, cue duration, and available nuisance variables such as gaze, heading, speed, action, and previous-trial history. Neural increment: add cue-period neural features available by cue offset, never later navigation activity, only after the baseline is frozen. Primary metric: held-out Δ log loss; report Brier and BA/AUROC as secondary probability/discrimination summaries. Positive control: decode an easier endpoint or task-condition label from the neural features alone under the same source-safe split; do not give that target label, its one-hot encoding, or a duplicate proxy to the control decoder. This checks an easier signal, not H1 itself. Gates: source-disjoint validation, recording-group provenance checks, nuisance-balance checks, and coherent source/session/temporal nulls. Stop criteria: no target/model swaps after freeze; stop if validation support or nuisance imbalance fails, or if the family null is non-positive.

For H1a, the minimal positive result would be held-out improvement in predicting future path components beyond start and goal on reserved source trials. For H1b, the minimal structural result would be reproducible geometry in raw, PCA, or CEBRA representations that tracks behavior-only path distance or route-component overlap after endpoint matching. CEBRA can be a measurement instrument, not the hypothesis. A behavior-conditioned CEBRA embedding uses path-derived context by design, so it still needs a separate held-out decoder and nulls.

For H2, the later artificial-agent comparison remains a stretch aim. RNN hidden activations are easy to observe but artificial; neural activity is biological but partial, noisy, sparse, and preprocessing-mediated. Similar geometry between an agent and hippocampal recordings would be a comparison of representational measurements, not proof that RNN units are neurons or that mechanisms are shared. That comparison should wait until H1 has a cleaner biological measurement object. Temporal and per-source hierarchical uncertainty models are future proposals, not fitted results in this report.

Negative or weak results are still useful. This report narrows the failure modes: exact-Q enumeration does not rescue the old claim; random pseudorow budget is not the answer; CEBRA training can memorize/source-transfer without source-disjoint validation; and source-preserving Track C is feasible but not yet positive.
