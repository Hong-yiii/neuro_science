## Status vocabulary

- **Current reading:** the retrospective package and frozen reading milestone;
  pending editorial work remains explicit.
- **Accepted historical evidence:** completed studies relevant to the report,
  not independent new replication or permission to refit.
- **Frozen protocol / execution history:** original authorization and methods,
  including failed attempts; not a pending run queue.
- **Superseded / archived:** retained for traceability, not a result to substitute
  for the accepted corrected authority.
- **Local-only:** ignored artifacts requiring the equipped host; not an off-host
  backup guarantee.
