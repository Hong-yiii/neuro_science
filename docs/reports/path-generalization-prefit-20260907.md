## Ranked hypotheses and predictions (before new response fitting)

H1: Finite synthetic sampling matters. At fixed source pools, additional training draws should reduce Monte Carlo variation and approach moment-exact linear/PCA references. Exact validation evaluation should remove validation-assembly noise. It cannot add independent biological information.

H2: Representation/optimization matters. At fixed input arrays, optimizer seeds, latent dimension and a longer predeclared training budget may alter transfer. Assembly and optimizer seeds must be crossed, not conflated. PCA29 retains all linear coordinates, but the complete standardized/regularized pipeline need not equal raw; a separate matched-head/no-extra-rescaling orthogonal-rotation test checks invariance. CEBRA receives raw standardized counts, never PCA outputs, and CEBRA29 is nonlinear/L2-normalized rather than an invertible full-dimensional control.

H3: The empirical source-conditioned relationship changes between splits. Source/session class-difference directions, decoder margin contributions, exact-Q baselines and source-budget/resplit diagnostics should expose this even without a neural encoder. A wrong-sign decoder does not prove a label bug or biological reversal.

H4: The global common-panel and stitched-row design hides usable real-trial evidence. A broader source-preserving analysis with endpoint/time controls may be better supported. Failure would motivate a quantitative data/design recommendation, not more arbitrary network capacity.

## Track A — exact conditional benchmark and sampling diagnosis

Primary old condition: middle directed component `D_N_R_T__N_R_M`, inferred endpoint pair `4->3`, primary29 panel, ten 100 ms cue bins. Keep original source splits fixed.

1. Enumerate every validation session-block source combination: absent 24, present 6. Assign each class total weight 0.5 and each combination uniform weight within its class. Distinct combinations remain dependent and can yield identical neural vectors. Weighted log loss/Brier and BA must respect this weighting; ordinary unweighted 30-row accuracy is not the balanced-Q target.
2. Replay all 12 accepted CEBRA checkpoints and saved raw/PCA C=1 heads on this exact support. Reproduce their old array predictions first. Separate old random-evaluation BA from exact empirical-Q BA.
3. Derive exact empirical-product moments. For whole-cue flattened session blocks, conditional means concatenate and conditional covariance is block diagonal. Balanced class mixture covariance is `0.5 Sigma_0 + 0.5 Sigma_1 + 0.25 delta delta^T`. The rank-one between-class term induces between-session covariance without measuring simultaneous interactions. Do not call the off-diagonal-masked matrix itself rank one.
4. For the shared 29-cell PCA space, average conditional moments over BOTH class and cue-bin, then use the law of total covariance. Shared time as well as class can induce cross-session covariance; the whole-cue rank-one statement cannot be transferred unchanged to this pooled-bin PCA.
5. Construct train-only moment-exact standardization/PCA and a moment-exact ridge classifier: labels +/-1, balanced empirical Q, minimize expected squared loss + lambda||w||^2, primary lambda=1; sensitivities 0.1/10 reported without winner selection. This is a provable estimator of the constructed Q, not a claim about the biological joint distribution.
6. Training rows/class {16,64,256,1024}, assembly seeds 0..19, matched raw-total/raw-binned/PCA3/PCA8/PCA16/PCA29 references. Fixed exact validation. Compare legacy C=1 with `C=64/rows_per_class`, which preserves the penalty relative to average logistic loss. Otherwise changing row count changes regularization as well as sampling. Report all arms, not a selected winner. Preserve source lineage for generated rows.
7. Source mean/margin contributions by session and leave-one-session-block-out; fixed whole-cue analyses primary. The old bin2 effect stays a labelled diagnostic, not the new primary window.
8. Source-preserving checks on existing relaxed40/11-session tensors: raw per-session total/binned and source-index controls; no off-session zero fill. Development resplits may be used as a separate explicitly exploratory sensitivity, not to replace unfavorable original validation.
9. Known-truth Gaussian controls with the same 29-cell/7-block layout (5,3,2,6,6,6,1 cells) and ten Gaussian coordinates per cell. Independent coordinate noise is an explicit simulation assumption, not a claim that real adjacent bins are independent examples: 100 fixed simulation seeds, source counts/class/session {3,10,30} for training and {1,5,20} for validation, per-coordinate class-mean differences {0,0.5} along one fixed signed vector. Fit moment-exact linear models, compare empirical-Q validation scores (exhaustive when tiny, otherwise fixed 2048 draws/class) to analytic true-Gaussian BA/AUROC. Under the zero-signal world, true BA is exactly0.5 for any frozen classifier even if finite-source synthetic validation is perfect or inverted. This is a methodological counterexample/positive-control study, not new biological data or a novelty claim.

## Prefit execution clarifications from code review

All clarifications below precede any new biological fits; they fix implementation/measurement ambiguities rather than select a favorable neural result.

- Finite-sample ridge at lambda1 is compared with the matching train-Q standardized exact-moment ridge. Logistic and ridge optimize different losses and are not claimed to share an infinite-draw optimum. For +/-1 ridge outputs, probability scores use clipped `(score+1)/2`; AUROC uses the unbounded decision score, avoiding clipping-induced rank ties.
- Source-budget curves use moment-exact ridge after nested source subsampling, so changing true source counts is not confounded with additional Monte Carlo assembly draws. The relaxed40 source-preserving arm uses one actual source trial per row, only its own session's observed cells, and raw-total/raw-binned/numeric-trial-index controls. Its average-loss regularization is fixed within session as source count changes.
- The separate source-identity one-hot control learns its vocabulary from training sources only. Every held-out source identity must be unseen; accidentally inserting validation identities into training features is prohibited.
- Shared-cell PCA derived from exact TRAIN class/time moments is both saved as a reference and compared with sample-fitted PCA using the same sampled rows and logistic heads. Full-coordinate PCA plus coordinate-wise head scaling is not an identity classifier.
- Track C continuous inputs are centered by TRAIN endpoint-specific means before residual standardization. This defines slope penalties on within-endpoint variation. Adding fixed endpoint-specific feature offsets must not change predictions; validation means are never learned.
- The fixed 24-component geometry catalog defines candidate targets; ranking uses training support only. Report all-context source totals separately from source totals in sessions that pass the >=20 model gate.
- Run identities include code, protocol, dependency sources and input hashes. Completed-case reuse verifies required artifacts and optimizer-step traces. Incomplete cases cannot be overwritten silently. Long/short runs compare numerical step-1000 weights and loss prefixes, not merely serialization bytes.
