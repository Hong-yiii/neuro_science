## Follow-up: what is the ratio between real sources and synthetic examples?

source-reuse table from another session, ending with:

> real indiv neurons -> psuedopopulation construction -> real sampling data

The manuscript must connect these quantities rather than present isolated counts.
The scientifically correct chain is: **recorded neurons within session-specific
trials → split real source trials → select condition-matched trials → concatenate
all neuron blocks → synthetic training/development rows**. Sampling is part of
construction; it does not create new real recordings.
