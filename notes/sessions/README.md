# Session Notes

One Markdown file per substantial working session. These notes preserve the
reasoning, discoveries, decisions, and next steps that are useful when resuming
work later.

Naming convention:

```text
YYYY-MM-DD-short-topic.md
```

Canonical facts should still be maintained in `docs/` or `context/`. Session
notes may summarize those facts but should link to the authoritative document.

Use diagrams where they clarify data flow, experimental structure, or analysis
constraints.
